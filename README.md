# Sensor & Signal Analysis Workbench (SSAW)

## Overview

Sensor & Signal Analysis Workbench (SSAW) is a research-oriented
software application designed to import, process, analyze, and
visualize sensor datasets.

## Objectives

- Develop a modular C++20 application.
- Implement signal-processing algorithms.
- Use Python for dataset generation and validation.
- Visualize time-series and frequency-domain data.
- Implement automated testing.
- Integrate persistent storage using SQLite.
- Develop a cross-platform build system.
- Document architecture and software development processes.

## Technology Stack

- C++20
- Python 3
- Qt 6
- CMake
- SQLite
- Catch2
- Git
- GitHub Actions

## Planned Features

- CSV dataset import
- Signal visualization
- Statistical feature extraction
- Fast Fourier Transform (FFT)
- Signal filtering
- Frequency analysis
- Anomaly detection
- Spectrogram visualization
- Dataset management
- Exportable analysis reports

Currently under development.
